# 宿舍管理系统

## 项目简介

本项目为2026夏季小学期课程作业。使用 Cpp Qt 技术栈开发实现的一款具有可视化界面的宿舍管理系统。本系统实现了对于学生、宿舍、宿舍楼三种在“宿舍管理”这一场景下的重要对象的管理。除了增、删、改等基础功能外，本系统还实现了如一键分配、快捷调宿等高级功能，同时拥有数据持久化储存的能力，以及一键生成样例数据，快速测试功能的能力。

## 功能

- 学生管理：新增学生、修改基础资料、性别纠错、退学籍，可按学号、姓名、年级、班级和入住状态筛选
- 宿舍资源：楼栋、宿舍、床位三级浏览，支持楼栋与宿舍的新增、属性修改和删除
- 住宿任务：指定、推荐或随机安排入住，保留学籍退宿，调宿与同宿舍换床，两名学生床位互换
- 高级调整：批量分配（随机、优先填满、尽量保持原宿舍楼三种策略）、全校重新安排、指定范围清退、两间宿舍整体调整
- 样例数据：一键生成可复现的样例数据，支持追加生成或清空后重新生成

## 技术栈

- 开发语言：C++ 17
- UI框架： Qt 6 Widgets
- 构建：CMake 3.16
- 第三方依赖：无

## 构建与运行

- 环境：Qt 6.10.2（msvc2022_64）+ MSVC 2022，仅依赖 Qt Widgets 模块
- 实际使用的 CMake 需为 3.22 或更高；`CMakeLists.txt` 中的 3.16 是脚本声明的最低版本，Qt 6.10 自身要求运行版本不低于 3.22
- 本机 Qt 路径与构建生成器由 `CMakeUserPresets.json` 补充，该文件不随仓库分发，克隆后需自行配置
- 构建产物目录 `build/`、`out/` 不纳入版本控制

## 数据存放

- 程序数据存放于可执行文件同级的 `userdata/school-data.json`，同目录保留一份 `.backup.json` 备份
- 该目录不可写时，改用系统的应用数据目录
- 数据以带版本号的 JSON 存储；正式文件损坏时自动尝试从备份恢复，两者均不可用时进入只读模式，此时拒绝一切写操作

## 核心设计

- 将学生、宿舍、宿舍楼设计为三种对象，各自负责管理其语义对应的角色
- 高层次对象通过具有唯一性的数据对低层次对象的数据进行存储，如宿舍使用学号对学生对象进行存储
- 为每个对象分别设计一个对应的Manager类作为单例，属于各自对应类的唯一归属，存储对象并处理内部的如交换、修改等操作
- 对于跨对象的操作如换宿舍，使用统一的school顶层类进行管理
